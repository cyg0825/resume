# 功能十：数据库设计

## 一、技术选型

本项目使用 **H2 内嵌数据库**（2.2 版本），以文件模式运行：

| 特性 | 说明 |
|------|------|
| 运行模式 | 内嵌：作为 jar 库运行在后端 JVM 里，不是独立进程 |
| 存储模式 | 文件模式：`jdbc:h2:file:./data/resume` → 数据持久化在磁盘 `.mv.db` 文件 |
| 兼容模式 | `MODE=MySQL`：保留反引号、AUTO_INCREMENT、LIMIT/OFFSET、DATE() 等 MySQL 语法 |
| 初始化 | JDBC URL 带 `INIT=RUNSCRIPT FROM 'classpath:schema.sql'\;RUNSCRIPT FROM 'classpath:data.sql'`，仅在 `.mv.db` 不存在时执行一次 |
| 关键字规避 | `NON_KEYWORDS=USER`：让 `user` 表名不触发 H2 关键字冲突 |
| 重置方式 | 停后端 → 删除 `data/` 目录 → 重启，H2 自动重建库 + 灌初始数据 |
| 备份方式 | 停后端 → 复制 `data/resume.mv.db` 即可，单文件完整快照 |

**为什么选 H2 而不是 MySQL**：个人简历项目数据量小（几个简历版本、几百条访问日志），H2 完全够用。零外部依赖——不需要单独启动数据库容器、不需要维护 MySQL 进程、不需要担心数据库挂了。MySQL 适合多用户、高并发、数据量大的场景，个人项目 H2 更轻。

### skill（技能）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | |
| version_id | BIGINT | NOT NULL DEFAULT 1 | |

## 五、设计决策总结

| 决策 | 理由 |
|------|------|
| H2 文件模式而非内存模式 | 数据持久化，重启不丢失。内存模式（`jdbc:h2:mem:`）只适合纯测试 |
| H2 MySQL 兼容模式 | 保留反引号、AUTO_INCREMENT、LIMIT 等语法，迁移 MySQL 时几乎不用改代码 |
| JDBC URL 带 INIT 参数 | 自动建表 + 灌初始数据，首次启动零配置。比 Spring Boot 的 `spring.sql.init` 更精准——只在 DB 文件不存在时执行 |
| 子表都有 version_id | 版本隔离的关键。删版本时用代码显式级联删除所有子记录 |
| experience 合并工作 + 项目 | 字段重合度高，合表 + type=1/2 区分更简单 |
| honor / portfolio 不绑版本 | 跨版本共享荣誉和作品集，同一人多版本简历一致 |
| profile 联系方式拆独立列 | 简单直接，查询方便。以后扩展加列即可 |
| skill 独立列（category + name + level） | 比 JSON 数组方案更简单，不需要 JacksonTypeHandler |
| site_config id 固定为 1 | 单例配置表，代码里直接 selectById(1) |
| is_default 用 TINYINT + UNIQUE | 允许 NULL 重复（非默认），只允许一个 1（默认版本）。比单独一张 default_version 关联表更简洁 |
| experience/education 没有外键约束 | 代码里显式级联删除，避免外键锁和跨表事务问题 |
| visit_log 字段精简 | 只存 ip、ua、referer、path、session_id、visit_time 六个核心字段，不绑 share_link_id 和 version_id（简化设计，足够统计分析） |

## 六、MyBatis-Plus 自动填充

所有实体都有 `create_time` 和 `update_time`。用 MetaObjectHandler 自动填：

```java
@Component
public class AutoFillHandler implements MetaObjectHandler {
    @Override
    public void insertFill(MetaObject metaObject) {
        this.strictInsertFill(metaObject, "createTime", LocalDateTime.class, LocalDateTime.now());
        this.strictInsertFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }
    @Override
    public void updateFill(MetaObject metaObject) {
        this.strictUpdateFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }
}
```

实体字段加 `@TableField(fill = FieldFill.INSERT)` 和 `@TableField(fill = FieldFill.INSERT_UPDATE)` 注解即可。

## 七、知识点总结

| 知识点 | 说明 |
|--------|------|
| H2 内嵌数据库 | 作为 jar 库运行在 JVM 里，不是独立进程。零配置启动 |
| H2 文件模式 | `jdbc:h2:file:/path/to/db`，数据持久化在 `.mv.db` 文件 |
| H2 INIT 脚本 | 只在 DB 文件不存在时执行一次 schema.sql + data.sql，已存在则跳过 |
| MySQL 兼容模式 | `MODE=MySQL` 让 H2 理解反引号、AUTO_INCREMENT、DATE()、LIMIT 等 |
| 1:N 版本隔离 | 所有子表带 version_id，确保删除版本时能级联清理 |
| UNIQUE + NULL 去重 | `is_default` 用 UNIQUE 约束，NULL 允许重复、只有一个 1 |
| MyBatis-Plus MetaObjectHandler | 自动填充 createTime/updateTime，避免手动 set |
| 独立列 vs JSON | 联系方式、技能都用独立列，比 JSON 数组方案更简单直接 |
| H2 备份 | 停后端 → 复制 `.mv.db` 文件即可，比 mysqldump 还简单 |
