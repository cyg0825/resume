Promise.all([

## 三、板块显示/隐藏控制

后台可以勾选"某个板块要不要显示"。前端从 siteConfig（或 profile 对象上的字段）读配置：

```javascript
const visible = {
  intro: siteConfig.showIntro !== false,
  education: siteConfig.showEducation !== false,
  work: siteConfig.showWork !== false,
  project: siteConfig.showProject !== false,
  skill: siteConfig.showSkill !== false,
  honor: honors.length > 0 && siteConfig.showHonor !== false,
  portfolio: portfolios.length > 0 && siteConfig.showPortfolio !== false,
}
```

**知识点**：用 `v-if="visible.xxx"` 控制 DOM 是否渲染，而不是 CSS `display: none`。好处：隐藏的板块不占滚动入场的观察对象，性能更好。坏处：隐藏→显示时需要重新挂载组件（本项目里无所谓，不会频繁切换）。

## 四、滚动入场动画（v-reveal 指令）

**文件**：`frontend/src/main.js`

```javascript
app.directive('reveal', {
  mounted(el) {
    el.classList.add('reveal')
    // 降级：如果浏览器不支持 IntersectionObserver，直接显示
    if (typeof IntersectionObserver === 'undefined') {
      el.classList.add('reveal-in')
      return
    }
    const io = new IntersectionObserver(
      (entries) => {
        entries.forEach((entry) => {
          if (entry.isIntersecting) {
            el.classList.add('reveal-in')
            io.disconnect()
          }
        })
      },
      { threshold: 0.06, rootMargin: '0px 0px -36px 0px' }
    )
    io.observe(el)
    el._revealIO = io   // 存引用，组件卸载时断开
  },
  unmounted(el) {
    el._revealIO?.disconnect()  // 清理观察器，防止内存泄漏
  }
})
```

**指令是什么**：Vue 的 directive 是给元素挂特殊行为的机制。`v-reveal` 就是自定义指令。Vue 提供几个钩子：`mounted`（元素挂到 DOM）、`unmounted`（元素从 DOM 移除）、`updated`（更新）。

**IntersectionObserver 是什么**：浏览器原生 API，用来观察元素是否进入视口。比自己写 `scroll` 事件 + `getBoundingClientRect` 性能好得多——浏览器自己做了节流和合并，回调在空闲时触发。

参数解释：
- `threshold: 0.06`：元素进入视口 6% 时就触发回调
- `rootMargin: '0px 0px -36px 0px'`：底部往内收 36px，相当于提前触发（元素还没完全进入视口就开始动画）

## 五、主题系统

**文件**：`frontend/src/store/theme.js`、`frontend/src/styles/theme.css`

### 三套主题

| 主题 | 主色 | 背景 |
|------|------|------|
| default（默认蓝） | `#4a7cff` | 浅灰 `#f5f7fb` |
| dark（深色） | `#6b8fff` | 深蓝黑 `#0f1419` |
| fresh（清新绿） | `#2ec4b6` | 薄荷白 `#f3fbf9` |

### 实现原理

用 CSS 自定义属性（CSS Variables）：

```css
/* 默认主题 */
:root {
  --color-primary: #4a7cff;
  --color-primary-light: #e8efff;
  --color-bg: #f5f7fb;
  --color-text: #1a2332;
  ...
}

/* 深色主题 */
:root.theme-dark {
  --color-primary: #6b8fff;
  --color-bg: #0f1419;
  --color-text: #e8eaed;
  ...
}
```

JS 切换主题只需要：
```javascript
document.documentElement.classList.remove('theme-dark', 'theme-fresh')
document.documentElement.classList.add('theme-dark')
localStorage.setItem('theme', 'dark')
```

**知识点**：CSS Custom Properties（自定义属性）用 `--前缀: 值` 定义，`var(--名)` 使用。它是运行时可变的，不像 SCSS 变量是编译期的。好处是可以在 JS 里动态切换，而且子元素会自动继承父级变量。

### 站点配置覆盖默认主题

后端返回的 siteConfig 里有 `primaryColor` 字段。如果管理员在后台自定义了主题色，前端会额外覆盖：

```javascript
document.documentElement.style.setProperty('--color-primary', siteConfig.primaryColor)
```

这样管理员可以从 3 套预设里选，也可以自己指定一个颜色。

## 六、响应式设计

三个关键断点：

| 断点 | 布局变化 |
|------|----------|
| ≥ 1400px | 双栏 50/50 |
| 1024 ~ 1400px | 双栏 40/60（左栏收窄） |
| 768 ~ 1024px | 单栏，左栏在上，右栏在下 |
| ≤ 768px（移动端） | 单栏，更大的间距，AI 聊天悬浮按钮隐藏 |

用 CSS Grid 的 `grid-template-columns: 40% 60%` 写死比例（好处：不会随内容高度失衡），窄屏时改成 `grid-template-columns: 1fr`（单列）。

## 八、分享入口的 Token 换取

访客拿到链接 `/r/{token}` 后，前端的 `ShareEntry.vue` 组件：

```
1. 路由参数 token = route.params.token
2. POST /api/share/access (body: {token})
3. 成功 → 拿到访客 JWT → localStorage.setItem('share_token', jwt)
4. 路由跳到 #/（ResumeHome），axios 拦截器自动带访客令牌
5. 失败 → 显示"链接无效/已过期/访问次数用完"的错误页面
```

## 九、知识点总结

| 知识点 | 说明 |
|--------|------|
| Promise.all | 并行发多个接口请求，全部成功后一起渲染 |
| v-if vs v-show | v-if 真正销毁/创建 DOM，v-show 只切换 display。隐藏多内容板块用 v-if |
| 自定义指令 | Vue directive，mounted/unmounted 钩子给元素绑定行为 |
| IntersectionObserver | 浏览器原生观察元素可见性，比 scroll + getBoundingClientRect 性能好 |
| CSS Variables | 运行时可变的 CSS 自定义属性，JS 可动态 setProperty 实现主题切换 |
| Media Query | CSS `@media (max-width: 1024px)` 做响应式布局 |
| CSS Grid | `grid-template-columns` 定义列，比 flexbox 更适合双栏等比例布局 |
| Element Plus Dialog | 后台弹窗组件，首页荣誉详情也用到 |
| 路由参数 | `route.params.token` 获取 URL 路径参数 |
