# 简历项目 — 整体架构与技术栈

## 一、项目定位

一个部署在个人服务器上的简历网站，核心诉求：

- **简历展示**：左侧头像信息 + 技能 + 教育 + 联系方式，右侧个人评价 + 工作经历 + 项目经历 + 荣誉证书 + 作品集。响应式，窄屏自动切单栏。
- **私密分享**：简历不是公开索引页面。访客必须通过专属分享链接（形如 `/r/{token}`）才能进入首页。未持有访客令牌且不是管理员的请求被引导到拦截页。
- **后台管理**：管理员登录后可编辑简历各模块、管理多个简历版本、生成/吊销分享链接、查看访问统计、配置主题、查看 AI 问答记录。
- **AI 智能问答**：首页右下角悬浮按钮打开聊天面板，访客可以用自然语言提问简历相关问题。未配置大模型时自动降级为本地关键词问答。
- **PDF 简历导入**：上传 PDF 简历 → 后端抽取文本 → 调用大模型结构化 → 生成新的简历版本，管理员校对后一键设为默认。
- **简历版本化**：简历所有内容按版本归档，可以创建多个版本（如 "测试岗版"、"测试岗版“），默认版本展示给访客，管理员可通过 `?versionId=x` 预览任意版本。
- **PDF 导出**：首页右上角按钮，前端把简历主体截成长图后按 A4 分页切割导出，保持双栏排版。

## 三、前后端通信约定

### 统一响应格式
后端所有接口都返回：
```json
{ "code": 200, "msg": "success", "data": {} }
```
非 200 的 `code` 表示业务错误。前端 axios 拦截器在 `res.code !== 200` 时会自动弹错并 reject。

### 认证方式
无状态 JWT。两种令牌：
- **管理员令牌**：登录后拿到，claim 里有 `kind=admin`。可以访问 `/api/admin/**` 所有写接口。
- **访客令牌**：通过专属链接 `/api/share/access?token=xxx` 换取，claim 里有 `kind=share`。只能访问简历只读接口 `/api/profile` 等和 POST `/api/ai/chat`、`/api/visit`。

### 端口
- 前端开发：`localhost:5173`，Vite 代理 `/api` 和 `/uploads` 到 `localhost:8080`
- 后端开发：`localhost:8080`
- 生产：Nginx 监听 80，后端容器 8080 通过 Docker 端口映射暴露；前端容器只暴露 80

## 五、核心架构图（文字描述）

```
访客/管理员浏览器
       │
       ▼
   Nginx (80)
   ├── 静态资源 → frontend 容器 (已编译的 dist/)
   ├── /api/**  → 反向代理到 backend 容器 (8080)
   └── /uploads/** → 反向代理到 backend 容器 (8080) 中的上传目录

backend (Spring Boot 3.2)
   │
   ├── JwtAuthenticationFilter（先于 Spring Security 默认过滤器执行）
   │     从 Authorization: Bearer <token> 解析 JWT
   │     → 管理员令牌 → ROLE_ADMIN
   │     → 访客令牌   → ROLE_VISITOR
   │     → 无令牌     → SecurityContext 为空
   │
   ├── SecurityConfig（URL 粒度权限控制）
   │     ├── /api/admin/**          → 仅 ROLE_ADMIN
   │     ├── GET /api/profile 等    → ROLE_ADMIN 或 ROLE_VISITOR
   │     ├── /api/auth/**, /api/share/access, /uploads/**  → 公开
   │     └── 其余 → denyAll
   │
   ├── Controller 层（@RestController）
   │     └── Service 层（业务逻辑）
   │           └── Mapper 层（MyBatis-Plus BaseMapper + 自定义 SQL）
   │                 └── H2（文件模式，内嵌，数据持久化在磁盘）
   │
   └── 可选外部调用：大模型 API（OpenAI 兼容格式）
         ├── Chat Completions（问答 + PDF 结构化）
         └── Embeddings（向量嵌入，语义检索用）
```

## 六、知识点总结

| 知识点 | 核心作用 |
|--------|----------|
| Vue 3 Composition API | 用 `setup()` + `ref`/`reactive`/`computed` 管理组件状态和逻辑，比 Options API 更适合逻辑复用 |
| Vue Router 守卫 | `beforeEach` 可以拦截未登录的管理员、未持令牌的访客 |
| Pinia Store | 比 Vuex 轻量。用 `defineStore` 定义全局状态，组件中直接 `useXxxStore()` 使用 |
| axios 拦截器 | 请求拦截器统一加 Authorization 头；响应拦截器统一处理错误和 401 |
| Vite 开发代理 | 开发时把 `/api` 代理到后端，避免跨域 |
| Spring Security 无状态配置 | `sessionCreationPolicy(STATELESS)` 关掉 Session，完全用 JWT |
| 自定义过滤器插链 | `addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class)` 在默认认证之前解析 JWT |
| MyBatis-Plus | 通用 Mapper 提供 `selectById`、`insert`、`updateById` 等单表 CRUD；条件构造器 `LambdaQueryWrapper` 用方法引用拼 where 条件；分页插件 `PaginationInnerInterceptor` |
| 统一异常处理 | `@RestControllerAdvice` + `@ExceptionHandler`，保证所有异常也返回 `{code, msg, data}` 格式 |
| Java HttpClient | Java 11 引入，替代第三方 HTTP 库。本项目用它调大模型 API |
| Record 类 | Java 16+ 不可变数据载体，本项目用作服务内部的数据传递对象（如 `KbCache`、`ImportResult`） |
| Docker Compose | 一个 YAML 编排多个容器，声明网络和依赖关系 |
